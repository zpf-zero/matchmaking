# 婚介小程序 · 数据库设计 v2.0（精简版）

> 数据库：`hunjie` · MySQL 8.4 · `utf8mb4` / `utf8mb4_general_ci` · InnoDB
> 主键统一 `bigint unsigned auto_increment`
> 通用字段：`created_at` / `updated_at` / `deleted_at`（软删，GORM 约定）

**设计原则**：小型项目，够用即可。不做预计算、不做冗余统计表、枚举值放代码不放数据库。

---

## 表清单（9 张）

| # | 表名 | 说明 |
|---|---|---|
| 1 | `user` | 用户账号（含管理员，role 区分） |
| 2 | `user_profile` | 详细资料 |
| 3 | `user_requirement` | 择偶要求 |
| 4 | `user_photo` | 相册 |
| 5 | `interaction` | 互动（浏览/喜欢/不喜欢） |
| 6 | `conversation` | 会话（= 配对关系） |
| 7 | `message` | 消息 |
| 8 | `blacklist` | 黑名单 |
| 9 | `report` | 举报 |

**没有 `admin_user` 表** — 管理员是 `role > 1` 的普通用户，同样微信登录。
**没有 `sys_dict` / `sys_config` 表** — 枚举值定义在 Go 常量里，通过 `/common/dict` 返回。
**没有 `user_stat` 表** — 统计数实时 count，小流量足够。

| role | 权限（向上包含） |

| 1 普通用户 | 仅 C 端功能 |

## 枚举常量（不建字典表）

定义在 `internal/model/enum.go`，通过 `GET /api/v1/common/dict` 一次性返回给前端缓存：

```go
var Education = map[int]string{
    1: "高中及以下", 2: "大专", 3: "本科", 4: "硕士", 5: "博士",
}
var IncomeLevel = map[int]string{

    4: "2万-3万", 5: "3万-5万", 6: "5万以上",
}

```

## 核心查询

### 推荐流（最高频）

```sql
SELECT u.id, u.nickname, u.avatar, u.last_active_at,
       p.age, p.height, p.education, p.income_level, p.city, p.marital_status
FROM user u
JOIN user_profile p ON p.user_id = u.id
WHERE u.deleted_at IS NULL
  AND u.status = 2
  AND u.gender = ?                    -- 异性
  AND p.audit_status = 1
  AND p.age BETWEEN ? AND ?           -- 我的择偶要求
  AND p.education >= ?
  AND p.income_level >= ?
  AND u.id NOT IN (SELECT to_user_id FROM interaction
                   WHERE from_user_id = ? AND type IN (2,3))
  AND u.id NOT IN (SELECT target_user_id FROM blacklist WHERE user_id = ?)
ORDER BY u.last_active_at DESC
LIMIT 20 OFFSET ?;
```

- `user` 走 `idx_status_gender`，`user_profile` 走 `idx_filter`
- 两个 `NOT IN` 子查询在单用户交互量有限时完全够用
- **不做 rank_score 预计算**。按活跃时间倒序，简单且效果不差
- 匹配度百分比在 Go 里算完返回给前端展示，不参与排序

### 会话列表

```sql
SELECT * FROM conversation
WHERE (user_a_id = ? OR user_b_id = ?) AND status = 1
ORDER BY last_message_at DESC;
```

### 统计数（实时 count，不建统计表）

```sql
-- 谁喜欢我的数量
SELECT COUNT(*) FROM interaction WHERE to_user_id = ? AND type = 2;
-- 待审核数量
SELECT COUNT(*) FROM user_profile WHERE audit_status = 0;
```
